# ✨ Lumina Wallpapers - Ultra-HD Wallpaper Hub & Studio

Lumina Wallpapers is a modern, high-performance web application designed for discovering, customizing, simulating, and downloading curated Ultra-HD & 4K wallpapers.

![Lumina Wallpapers](https://images.unsplash.com/photo-1518709268805-4e9042af9f23?w=1600&auto=format&fit=crop&q=80)

---

## 🌟 Key Features

- **🎨 Wallpaper Studio & Editor**: Apply real-time filters (brightness, contrast, saturation, blur, sepia, hue), aspect ratio adjustments, and color grading.
- **📱 Real-time Device Simulator**: Preview any wallpaper live inside mockups for iPhone 15 Pro, Samsung Galaxy S24 Ultra, MacBook Pro, and iPad Air.
- **🔍 Smart Search & Categorized Filters**: Filter by themes (Cyberpunk, OLED Dark, Minimalist, Anime, Nature, Abstract, Architecture, Space, etc.) and color palettes.
- **⚡ Live Pexels API Integration**: Search millions of high-resolution stock wallpapers with custom API key support or fallback curated library.
- **💖 Favorites & Local Collection**: Save, bookmark, and organize favorite wallpapers locally with instant access.
- **🧘 Zen Screensaver Mode**: Distraction-free, immersive full-screen slideshow experience.
- **🚀 One-Click Downloads**: High-speed resolution-aware wallpaper downloading.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS with glassmorphic tokens, CSS variables, and fluid layouts
- **Icons**: [Lucide React](https://lucide.dev/)
- **Effects**: Canvas Confetti
- **Deployment Target**: [Vercel](https://vercel.com/)

## 🚀 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/codewithawaiskhan/lumina-Wallpapers.git
cd lumina-Wallpapers
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

---

## ☁️ Deployment on Vercel

The project includes `vercel.json` optimized for Single Page Application (SPA) routing:

1. Import the repository into [Vercel](https://vercel.com/).
2. Keep default Vite framework preset.
3. Click **Deploy**.
